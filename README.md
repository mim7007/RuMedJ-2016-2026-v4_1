## 📌 О проекте

Данный репозиторий содержит **полностью воспроизводимый код** и результаты исследования, посвященного описательному профилированию **российских и белорусских медицинских журналов**, индексируемых в Scopus, за период **2016–2025 гг.**

**Анализ включает:**

- Динамику публикационной активности: среднее и общее количество статей на журнал (`P`);
- Динамику нормализованного влияния (`SNIP`);
- Структурные сдвиги по узким тематикам (ASJC);
- Индивидуальные траектории 221 журнала (включая новые издания);
- Уровень самоцитирования и его связь со стабильностью журналов;
- Ежегодный прирост и появление новых журналов;
- Корреляционный анализ между ростом числа статей и ростом SNIP по тематикам;
- Верификацию целостности данных (10 ключевых проверок).

**Ключевые методологические решения:**

- Отбор журналов строго по медицинским ASJC (27xx, 29xx, 30xx) на основе экспертного списка;
- Исключение немедицинских тематик (2502, 3201, 1207) с принудительной проверкой;
- Две методологии расчета динамики: по средним за периоды (для тематик) и по фиксированным годам (для журналов);
- Полная воспроизводимость в Google Colab.

## 🧪 Методология

Фильтрация данных:
1. Отбор журналов: Из экспертного списка выбраны только журналы с медицинскими ASJC (27xx, 29xx, 30xx) с принудительной проверкой.
2. Фильтрация по ISSN: Основной датасет отфильтрован по ISSN отобранных журналов.
3. Временной горизонт: Оставлены только записи за 2016–2025 гг.
4. Очистка: Удалены дубликаты (журнал-год) и пропуски в ключевых колонках (P, SNIP, % self cit).
5. Исключение немедицинских журналов: Вручную исключены записи с ASJC 1207.

Расчет динамики:
- Для тематик (ASJC): разница средних значений за периоды 2016–2020 и 2021–2025 (сглаживание годовых колебаний).
- Для отдельных журналов: разница значений в 2016 и 2025 гг. (оценка реальной траектории развития). Журналы с 1 годом данных включаются в общую таблицу с пометкой "new".

Статистические тесты:
- Сравнение групп: t-тест Уэлча (неравные дисперсии).
- Корреляционный анализ: коэффициент Пирсона.

Верификация данных (10 проверок):
1. Дубликаты (журнал + год) — должно быть 0.
2. Пропуски в ключевых колонках — должно быть 0.
3. Аномальные значения SNIP (< 0 или > 10) — должно быть 0.
4. Журналы без медицинских ASJC — должно быть 0.
5. ISSN, не найденные в экспертном списке — должно быть 0.
6. Диапазон лет — ожидается 2016–2025.
7. Количество записей по годам — стабильность.
8. Журналы с неполным рядом данных (< 10 лет) — допустимо.
9. Самоцитирование > 100% — должно быть 0.
10. Отрицательное P — должно быть 0.

## 📈 Ключевые результаты

- Итоговая выборка: 1600 записей, 221 журнал (220 установившихся, 1 новый), 58 тематик
- Среднее число статей на журнал: ~217–223 за период. Суммарный объем публикаций вырос с 12 243 (2016) до 48 014 (2025).
- Динамика SNIP: медиана выросла с 0.14 до 0.27 (в 1.9 раза), средний SNIP стабилен (~0.30)
- Корреляция P и SNIP: r = 0.113 (слабая положительная)
- Самоцитирование: среднее ~20%, корреляция с CV_SNIP = 0.034
- Топ-5 растущих тематик: 2746 (хирургия), 2700 (общая медицина), 2701 (медицина), 2739 (внутренние болезни), 2730 (онкология)
- Журнал-лидер роста SNIP: Diabetes Mellitus (ΔSNIP = +0.63)
- Пик появления новых журналов: 2020 год (83 новых издания)
- Корреляция роста статей и SNIP по тематикам: r = -0.020, p = 0.885 (связь отсутствует)
